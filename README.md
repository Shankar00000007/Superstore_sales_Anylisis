Excel Superstore Sales Analysis
This project analyses Superstore sales data using Excel pivot tables and charts.
Superstore Sales Dataset from Kaggle, with about 9,800 orders and 18 columns.
Tools used. Microsoft Excel, pivot tables, pivot charts, Text to Columns for date cleaning.
Key insights. West has the highest regional sales at 710,219.68, and South has the lowest at 389,151.46.
Technology is the top category at 827,455.87, and Office Supplies is the lowest at 705,422.33.
Sales dipped slightly in 2016 compared to 2015, then grew steadily in 2017 and 2018, with 2018 the highest at about 722,052.
Sheets included. Region Pivot, Category Pivot, Year Trend, Insights, and the cleaned sales data.
